# Gemflow 界面示意（2026-10-13）

Gemflow 作为「可以观察、可以干预」的监督层，在 Claude Code desktop 里长什么样。这一版是方向定稿，改版以它为底。

- 画布（可直接在页面上改）：https://claude.ai/artifact/Aw9u6PXPAaXpFZYWppafY8
- 本目录是画布的源文件：`canvas.json` 是索引（每块画板在画布上的位置与大小），每个 `*.dc.html` 是一块画板，自包含。改版时改这里的文件，再用 Artifact 工具发布回同一个画布（`root` 指向本目录的上一级结构：文件要放在 `project/` 下），或者在页面上改完再把源文件拉回来。

## 画板

| 文件 | 内容 |
|---|---|
| `Main.dc.html` | 桌面全景：对话区、输入框上方的状态带、右侧 Gemflow 看板（停在「待处理」） |
| `Inbox.dc.html` | 待处理：只有人能做的事，按等待时间排、按类型分组——要批准、要回答、要勾选、卡住了 |
| `Items.dc.html` | 工作项：每个分支一项，按阶段分组，当前项高亮，有「已暂停」的；底部是未绑定的 backlog |
| `Journal.dc.html` | 记录：顶部「自上次之后」摘要；筛选；时间线标谁做的；证据可展开看出处；拒绝条目就地放行 |
| `Sessions.dc.html` | 会话：每条 prompt 按当时阶段分组，行前一个三角，点一行展开，展开后的卡片里拆成新会话、删除这一轮；导出会话 |
| `FlowTools.dc.html` | 流程页与工具页：状态竖排、出边标判断者与通行要求；词典表加「在当前状态的处境」列，可就地改 |
| `Dialogs.dc.html` | 设置、升级、关于 |
| `Share.dc.html` | 分享：分享什么（现在在哪 / 记录 / 本会话 / 流程与词典）、怎么给 |
| `Band.dc.html` | 状态带的各种时候，以及桌面提醒 |

## 这一版定下的

- **状态带 = 在哪 + 此刻最紧要的一两个动作 + 其余在「待处理」里。** 行首是 GEML 的 G 标（终端里用红色 `G` 字样），然后工作项、阶段、下一道通行要求读的变量、下一步；行尾按紧要程度放第一项的动作（批准/打回、勾变量、放行一次/这里也允许、回答、继续、重试），再是「待处理 N」按钮。终端里按钮换成按键提示与 `/gemflow` 子命令。
- **看板标签页顺序：待处理 → 工作项 → 记录 → 流程 → 工具 → 会话。** 打开默认在待处理；前五个围着工作项转，会话是对话这一维的，单独放在末尾。
- **待处理是核心对象**：所有只有人能做的事排成一列，每项一个动作；有新项时桌面提醒（可关）。
- **记录页顶部是「自上次之后」的人话摘要**；证据可展开看凭什么、哪次调用、在哪份内容上、还算不算数。
- **会话页**：prompt 历史按阶段分组，折叠行只有三角、时间和两行字（没有图标，行间没有线）；点一行展开，展开后的卡片里「拆成新会话」「删除这一轮」，终端行尾另有「跳转」；每个会话标题旁有「导出」，只导出 GEML，按下先问存到哪（下载 / 桌面 / 本项目 / 自填路径）。
- **暂停**：冻住工作项，模型推不动，证据照记；工作项列表和状态带都显示。
- **分享**：四种内容、五种给法；记录里只有命令行、文件名和退出码，可去掉绝对路径。
- **国际化**：状态带、看板、提醒、`/gemflow` 的文字都走同一份词条表；设置里「偏好语言」默认跟随系统；流程自己的标题和说明保持作者写的语言。
- **头部常驻**：G 标、名字、版本与「有新版本」、分享、设置、升级、关于。
- **配色**：红只用在 G 标和「待处理」计数；主按钮近黑；证据绿、拒绝暗红、等批准琥珀；系统字体，等宽只给分支名、命令和哈希。
