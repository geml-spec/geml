# 拆分会话

拆分以"轮"为单位：一轮从用户发的一条消息开始，包括 Claude 的回答、中间所有工具调用和子代理，到用户下一条消息之前为止。拆分会做这些事：

- 把选中的几轮写进一个新会话（记录文件 + 桌面端侧边栏条目），子代理的记录也一起搬过去；
- 原会话里删掉这几轮，后一条消息接回到前一条后面；
- 动手前把原会话备份到 `~/.claude/session-split-backups/<时间>-<会话前缀>/`，里面的 `manifest.json` 记着新旧两边的文件位置。

脚本是本目录下的 `split-session.mjs`，用 Bash 调 `node`。不带 `--session` 时就处理当前会话。

## 步骤

1. **定会话。** 默认是当前会话。用户点了别的会话，就用 `list_sessions` 或 `search_session_transcripts` 拿到它的 `local_…` id，传给 `--session`。

2. **列出轮次。**

   ```bash
   node "<本 skill 目录>/split-session.mjs" list
   ```

   每行一轮：`#序号 时间 用户那条消息的开头 [标记]`。带标记的轮次不能拆：
   - `当前这一轮`：就是用户刚发的这条拆分指令，正在进行；
   - `含压缩边界`：跨着上下文压缩的边界，拆了会话就续不上。

3. **选要拆的轮次。** "这个问题"指的是拆分指令之前刚聊的那个话题，按每轮开头判断：
   - 往前数，和它同一个话题、连在一起的几轮都算进去。用户追问的那几轮属于同一个问题；
   - 用户点了话题名（"把关于 XX 的那段拆出去"），就找对应的那几轮；
   - 一眼能确定就直接拆，不用再问；有两种以上说得通的范围时，用 AskUserQuestion 让用户选，选项用中文、写上轮次的开头。
   - 中间夹着别的话题的几轮，也能一次拆进同一个新会话，比如 `--turns 3,5-6`。新会话里按原来的先后接起来，原会话里每个空档各自接回前一轮。
   - 看板上勾选后交来的拆分，会给出每一轮的 uuid。这时用 `--uuids <uuid,uuid,...>` 选轮，不用再按时间和开头去对；`list --json` 里每轮也带着 uuid。
   - `--uuids` 也接受插话的 uuid（用户在一轮进行中插的话，`list --json` 的 `messages` 里列着）。插话连同它那一轮一起选时跟着那一轮走；单独选时只搬那句话：它成了新会话里用户的一条消息，那一轮里之后的回答留在原处。删除时同样只删那句话。

4. **起标题、执行。** 标题用中文、几个字，概括拆出去的内容。

   ```bash
   node "<本 skill 目录>/split-session.mjs" split --turns 5-6 --title "周末出行安排"
   ```

   想先看会搬哪些、不写文件，就加 `--dry-run`。

5. **核对。** 再跑一次 `list`，确认那几轮已经不在原会话里了。

6. **汇报。** 告诉用户：
   - 拆走了哪几轮（序号 + 开头）、新会话的标题；
   - **新会话要完全退出桌面端再打开后才会出现在侧边栏**（桌面端只在启动时读会话列表）；
   - 原会话里那几轮要**完全退出桌面端再打开**才会从窗口里消失，只重新打开这个会话不够；拆的是当前会话的话，这次对话里我也还记得它们；
   - 备份目录的位置。

   拆分指令和这次汇报本身留在原会话里，正好当作"这里拆走过一段"的记号。

## 删除

用户要删掉某几轮、不另建会话时用 `remove`，选轮次的规则同上：

```bash
node "<本 skill 目录>/split-session.mjs" remove --turns 5
```

同样先把原会话备份，再删掉这几轮、后一条接回前一条，不建新会话。`--dry-run` 只看不写。删完再 `list` 核对，汇报删了哪几轮（序号 + 开头）和备份位置，并提醒用户：要**完全退出桌面端再打开**，那几轮才会从窗口里消失，只重新打开这个会话不够。

## 撤销

备份目录里有原会话拆分前的记录文件。原会话拆完之后没再聊过的话，按 `manifest.json` 里 `files` 记的位置恢复：

1. 退出桌面端；
2. 把备份的 `.jsonl` 拷回 `files.original`；
3. `files.subagentsBackedUp` 列的子代理文件（备份目录里的 `<名字>.jsonl` 和 `.meta.json`）挪回 `files.subagentsHome`；
4. 删掉 `files.newJsonl`、`files.newDesktop` 和 `files.newDir`。

拆完后原会话又聊过的话，直接拷回会丢掉后来的内容，要先跟用户说清楚再动。删文件前先确认是用户要撤销。
