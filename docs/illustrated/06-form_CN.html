分工

谁描述、谁渲染、谁校验

「校验放在哪」的答案。没有变。

描述 文档 .geml

form 和它的 form-* 子块。写的是：有哪些字段、什么类型、必填否、选项是什么，以及格式和范围的声明，这些键来自 geml-form/v1 profile。

不做：不求值、不校验、不提交。§9.1，§8.3(5)。

渲染 样式 / profile

决定长什么样：单页还是 Steps、分组要不要折叠、下拉还是单选组、要不要把 min/max 显示成提示。

不做：不判断对错。渲染出来的是禁用预览，它拿不到输入。

校验 · 提交 handler

宿主按名字注册（handler=onboarding）。唯一拿到用户输入的地方：执行声明的格式约束，再加文档不承载的业务规则。

不做：不决定字段长什么样，不改文档。

「约束」是格式和范围这类可以声明的东西，写在文档里。「校验」是动作，只发生在 handler。样式里没有校验，只有长相。

form-* 家族：一个 form，四种子块

评审点 2

多值字段和重复组

两个长得像、其实不同的东西。form-group 取代了上一版的 type=group，并且天然可重复。

评审点 3

选项：form-options

契约不变，载体换成专门的类型。type=select 的值必须落在选项表的 value 列里。

评审点 4

type 与约束

type 回到 7 个纯值形状。约束属性来自 profile，只声明不求值。

评审点 5

label · description · form-note：三种文字各归哪里

短的在属性，长的在 form-note，form-field 正文永远为空。
