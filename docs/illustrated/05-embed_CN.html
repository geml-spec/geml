GEML 块图解 · embed

embed 站在别处内容的位置上：src= 命名另一份文档（或本文档）里的一节、一块、一段散文，渲染时那份内容出现在这里。它没有自己的正文，有的是一套关于「取什么、怎么取、什么不能取」的规则：part= 切标题的哪部分，被嵌文档必须作为独立文档解析，目标必须是 .geml，scheme 受限，循环报错。行内还有一个小兄弟 ![[#id]]。这一页把这些全部实测一遍，并画出 GEP-0010 用 embed 做翻译投影、GEP-0011 让叶值坐标做投影目标的两个草案。

规则出处状态
1src= 命名内容：一份文档，可带片段。缺 src 是 embed-missing-src error；正文被忽略并 ignored-embed-body warning。src= 和任何引用一样受检：片段不存在是 unresolved-reference error。§3 · §5 · A.2规范已定
2片段命名标题 → 整节：标题本身及其后直到下一个同级或更高级标题前的所有块。命名块 → 那一块。命名散文地址（#budget-before-detail）→ 那段散文。无片段 → 整份文档。§3 · §4规范已定
3part= 只对标题目标有意义：head 标题行本身，body 标题下全部，intro 到第一个子标题前，whole 默认。head 与 body 划分 whole。与 geml get --head/--body/--intro 是同一套词。目标不是标题时全体照用；未知值 bad-embed-part warning，全体照用，因为悄悄选空是 §8.2 要防的失败。§3 · A.3规范已定
4被嵌文档作为独立文档解析后再选目标，不是拼接文本。它的 meta、引用、相对路径的基、外部数据都相对它自己解析；链条每一层都是下一层的基。§3规范已定
5目标必须是 .geml：别的文件是 embed-target-not-geml error，字节永不按 GEML 解析。scheme 只许 http、https、mailto、tel，其它在建模时拒绝并清空属性（unsafe-embed-scheme error），检查时忽略 U+0000–U+0020。跨文档解析限于 --root，解析符号链接后再判，fail closed。§3 · §9.4 · §9.5 · A.2规范已定
6嵌套链回到正在展开的文档是 transclusion-cycle error，报出链条，不跟进。§9.3 · A.2规范已定
7行内投影 ![[#id]] / ![[doc.geml#id]]：目标必须是单段 text，把它的行内内容插进句子；![alt](doc.geml) 用媒体语法嵌文档是 media-target-is-document error。! 是投影前缀，没有 ! 的 […] 是导航。§5.1 · §5.2 · B.4规范已定
8渲染：块级展开成 section.transclusion id data-src，内容原样；行内投影是 span.transclusion-inline data-src。--to html实测
9坐标：embed 在本文档模型里是空体 raw 块，内部没有可寻址单元，#embedB[1]["col"] 不解析，读写都不行；反向允许一种：叶值坐标可作投影目标，![[a.geml#vars["version"]]] 得到 1.4；位置切片（一行、一列）不可作目标。GEP-0011GEP 草案
10翻译投影：translate-to= 由 geml-translator/v1 profile 放行，在 meta 上是文档默认，在 embed 上覆盖，none 保留一块不译；translator= 保留给第二个引擎出现之后。一份译文只含 embed，id、顺序、非散文字节只有一个家。无 profile 时是 unknown-attribute warning。GEP-0010GEP 草案
11外部数据和媒体 src 由渲染器在渲染时取，渲染器把它们当不可信输入，可限定同源、要求 opt-in。§9.4规范已定
part=

嵌一节，或者一节的一部分

同一个标题目标，五种取法。左边 a.geml 是源，b.geml 是嵌的一方。

基

被嵌文档是独立文档，散文和整篇都能嵌

相对路径、meta、外部数据都相对源文档解析。嵌的一方只决定内容出现在哪。

失败

六种失败，加一个循环

五个 error 两个 warning，与 A.2 逐条对上。

行内

行内投影、叶值坐标、坐标穿不过 embed

![[…]] 把一段话或一个值放进句子里。GEP-0011 划了两条线：什么能当目标，坐标能不能穿过 embed。

翻译

一份译文只含 embed

GEP-0010：翻译是沿语言轴的投影，和沿格式轴的 .md 投影同一个形状。profile 已注册，规范未收。
