GEML Blocks Illustrated · code and data

This page covers code and data. They share a page because they are mirror images: code holds text the processor never interprets, data holds a value that must parse; the two share one src= route syntax, yet weigh "cannot resolve" in opposite ways. Each rule names its source; the right-hand side is measured output from geml check, geml get and --to html.

code

code: the text itself, or a route to a region of source

The body is text and is never run (§9.1). Instead of copying code, src= can point at a file and a line range, and drift is caught.

data

data: a verified value tree

Added by GEP-0005. code carries text that must not be interpreted; data carries a value that must parse.
