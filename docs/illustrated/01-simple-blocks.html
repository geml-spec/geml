GEML Blocks Illustrated · The Simple Four

This page covers meta, math, note and text — the four smallest types — plus the fence, id and attribute rules every type shares. Each rule names its source: a section of the specification, or a GEP. The right-hand side is not an imagined rendering but what the processor actually does: the diagnostics geml check prints, the addresses geml list gives, the tags --to html emits. Two places where the implementation disagrees with the specification are flagged on the board.

Shared

Rules every type shares

How fences open and close, how unknown things degrade, which attributes anyone may use. With these settled, each type's own section is short.

meta

meta: a key–value body that merges into one namespace

It does not render. It supplies three things: the document title, the values {{key}} interpolates, and the profile declaration.

math

math: a display formula

The simplest type. Raw body, handed to a math renderer; the processor's only duty is to leave it alone.

note

note: a callout with chrome

Flow body, may nest blocks. The whole difference from text is the chrome.

text

text: an id for a run of prose, nothing more

Added by GEP-0004. A neutral container with no chrome; it exists for geml get/set #intro, [[#intro]] and versioned rollback.
